# Épreuve de niveau : un pipeline qui dit vrai

Fin du niveau 1. Un pipeline vert qui ne garantit presque rien de ce qu'il
affiche : quatre promesses, aucune tenue, et aucun défaut nommé.

Plan du niveau :
[Labs GitLab CI/CD](https://www.stephane-robert.info/docs/pipeline-cicd/gitlab/labs/).

```bash
dsoxlab run gl-ep1-un-pipeline-qui-dit-vrai
# Le projet est dans la forge du lab : http://gitlab-1.lab/root/pipeline-craft
# Une copie du dépôt attend dans /opt/dsoxlab/gl-ep1/pipeline-craft (branche main).
dsoxlab challenge gl-ep1-un-pipeline-qui-dit-vrai
dsoxlab check gl-ep1-un-pipeline-qui-dit-vrai
```

Épreuve sans indice : les quatre défauts ne sont pas nommés, et la note se
prend sur l'état laissé dans la forge, jamais sur les commandes tapées.
